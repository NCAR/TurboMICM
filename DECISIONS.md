# Decisions

- TS1 uses a checked-in normalized JSON configuration generated by
  `tools/import_ts1.py` from MICM's permitted `ts1_mechanism.hpp` input. This
  keeps compilation and execution independent of MICM and MUSICA.
- The normalized mechanism format records phase species metadata explicitly:
  `third_body`, `molecular_weight`, and `diffusion`. TS1's surface reaction
  species need their phase diffusion metadata, and third-body species are
  parameterized on air density rather than a concentration state variable.
- The configuration reader supports JSON with the Python standard library and
  YAML through the pinned PyYAML package in the local prefix environment.
- `make cpu` targets portable C11 and OpenMP. The Makefile selects OpenMP flags
  based on the compiler and operating system, while optimization flags remain
  controlled only by `OPTFLAGS`.

These choices describe the current foundation. Unsupported configuration rate
types and TS1 rate-parameter extensions must be added before the mechanism path
is complete.
